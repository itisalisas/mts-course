## Предусловия

Считаем, что все, что устанавливалось в первом домашнем задании, уже установлено корректно.

Для того, чтобы скрипт и конфиги были доступны на team-9-jn, находясь в директории homework-02, необходимо скопировать файлы:

```
scp -r . team@176.109.91.11:/tmp/yarn
```
И затем необходимо подключиться на team-9-jn (176.109.91.11).

```
ssh team@176.109.91.11
```

## Запуск

В скрипте для нод настраиваются конфугационные файлы `yarn-site.xml` и `mapred-site.xml` и на NameNode запускаются сервисы `yarn` и `historyserver`.

Скрипт запускается командой

```
/tmp/yarn/yarn_script.sh
```

## Веб-интерфейсы

Для того, чтобы увидеть веб-интерфейсы, необходимо выйти из всех ВМ и выполнить команду:

```
ssh -L 9870:192.168.1.39:9870 -L 8088:192.168.1.39:8088 -L 19888:192.168.1.39:19888 team@176.109.91.11
```

После чего можно открыть в браузере следующие адреса:

- http://localhost:9870/ (интерфейс hdfs)
- http://localhost:8088/ (интерфейс yarn)
- http://localhost:19888/ (интерфейс historyserver)
