```

```
И затем необходимо подключиться на team-9-jn (176.109.91.11).

```
ssh team@176.109.91.11
```

## Веб-интерфейсы

Для того, чтобы увидеть веб-интерфейсы, необходимо выйти из всех ВМ и выполнить команду:

```
ssh -L 9870:192.168.1.39:9870 -L 8088:192.168.1.39:8088 -L 19888:192.168.1.39:19888 -L 10002:192.168.1.39:10002 team@176.109.91.11
```

После чего можно открыть в браузере следующие адреса:

- http://localhost:9870/ (интерфейс hdfs)
- http://localhost:8088/ (интерфейс yarn)
- http://localhost:19888/ (интерфейс historyserver)
- http://localhost:10002/ (интерфейс hive)

## Запуск задания MapReduce

Уже есть тестовая база данных test.some_data с загруженными данными, на которой можно проверить работу hive. Чтобы это сделать, необходимо выполнить следующие команды:

Необходимо подключиться на team-9-jn (176.109.91.11).
```
ssh team@176.109.91.11
```

Далее переключиться в пользователя hadoop.
```
sudo -i -u hadoop
```

Далее запустить beeline с желаемым запросом (в данном случае - количество строк в таблице test.some_data)
```
beeline -u jdbc:hive2://team-9-nn:5433 -e "select count(*) from test.some_data;"
```
