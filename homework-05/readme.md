## Запуск

Скрипт запускается командой

```
/tmp/prefect/prefect_script.sh
```

## Что делает этот скрипт

* Активирует виртуальное окружение
* Скачивает в виртуальное окружение prefect
* С помощью spark трансформирует датасет, партиционирует его и сохраняет результат в виде таблицы
* Оркестрирует этот процесс библиотека prefect

## Датасет

Датасет содержит данные об авиарейсах. Он состоит из 1.000.000 строк и имеет следующую схему:
```
 |-- FL_DATE: date (nullable = true)
 |-- DEP_DELAY: short (nullable = true)
 |-- ARR_DELAY: short (nullable = true)
 |-- AIR_TIME: short (nullable = true)
 |-- DISTANCE: short (nullable = true)
 |-- DEP_TIME: float (nullable = true)
 |-- ARR_TIME: float (nullable = true)
```

## Трансформирование датасета

Были выполнены следующие трансформации данных об авиарейсах:

1. Извлечение года (`YEAR`)
2. Категоризация задержек вылета (`DEP_DELAY_CATEGORY`)
3. Определение дальних рейсов (`IS_LONG_DISTANCE`)
4. Расчет средней скорости (`AVG_SPEED`)
5. Определение выходных дней (`IS_WEEKEND`)

Затем датасет был партиционирован по колонке `IS_LONG_DISTANCE`. Взятый нами датасет имеет маленький размер, поэтому в более чем 2 партициях нет необходимости.
